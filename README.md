# Renalddva. — Portfolio Website

Selamat datang di repository website portofolio pribadi saya! Website ini dirancang untuk menampilkan profil, riwayat pendidikan, pengalaman profesional, keahlian teknologi, serta karya-karya unggulan yang telah saya kerjakan.

Dibuat dengan antarmuka pengguna (UI) yang modern, bersih, dan interaktif menggunakan teknologi web fundamental.

## Fitur Utama
- **Modern & Clean UI**: Desain dengan skema warna gelap (dark theme) yang profesional dan nyaman di mata.
- **Fully Responsive**: Tampilan dioptimalkan untuk berbagai ukuran layar (Desktop, Tablet, Mobile).
- **Interactive Animations**: Dilengkapi dengan *micro-interactions* dan animasi gulir (scroll reveal) yang mulus.
- **Dynamic Typing Effect**: Efek teks mengetik otomatis pada bagian Hero untuk menambah kesan hidup.
- **Horizontal Scroll Portfolio**: Galeri proyek unggulan yang dapat digeser ke samping dengan mudah.

## Teknologi yang Digunakan
Website ini dibangun sepenuhnya menggunakan teknologi statis tanpa *framework* berat, sehingga memuat halaman dengan sangat cepat:
- **HTML5** untuk struktur halaman semantik.
- **CSS3 (Vanilla)** untuk styling, animasi, layout (Flexbox & Grid), dan sistem desain *Custom Properties* (variabel CSS).
- **JavaScript (Vanilla JS)** untuk logika interaksi, navigasi *smooth scroll*, efek mengetik, dan validasi form sederhana.
